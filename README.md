# Portal de Serviços (Protótipo)

Base inicial para modificações no protótipo do portal de serviços.

## Estrutura

- `index.html`: estrutura principal da interface.
- `assets/styles.css`: estilos base do protótipo.
- `assets/app.js`: lógica de listagem, busca e exibição de serviços.
- `assets/services.json`: dados mock iniciais.

## Execução local

```bash
npm run start
```

Depois, acesse `http://localhost:8000`.
